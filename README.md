# Правила
* **Запрещён технический вред серверу** - лаг-машины, перегрузка чанков, засорение диска через мод на картины и т.д.
* **Запрещено читерство** - использование стороннего ПО, дающего серьёзное преимущество над другими игроками в бою и развитии. Небольшие QoL-фичи, такие как карта или зум, разрешены. Если не уверены, считается ли что-то читом, уточните у [стаффа](#общение-и-поддержка) сервера.
* **Запрещено гриферство** - вред игрокам и результатам их деятельности ради веселья или обогащения за счёт других.
* **Запрещено нарушение правил, дублирующих правила дискорд сервера** (подробная версия правил [здесь](https://discord.com/channels/958653033342959666/963831955957379072/1135880424216862820)):
  * Не проявляйте агрессии и не дискриминируйте
  * Запрещено пользоваться уязвимостями формулировок, использовать дополнительные аккаунты для обхода наказаний и правил
  * Не публикуйте NSFW-E контент
  * Запрещено ERP с участием несовершеннолетних
  * Не занимайсятесь оффтопингом и не спамьте
  * Не создавайте помех для общения в голосовых каналах на дискорд сервере или через мод, добавляющий войс чат

# Как зайти на сервер?

## Лаунчер
Подойдёт **ЛЮБОЙ** лаунчер. Лично от себя могу порекомендовать [Prism Launcher](https://prismlauncher.org/download/). По умолчанию он требует лицензию, но это можно отключить. Для этого нужно изменить файл `PrismLauncher/accounts.json` вручную или через команду:
> Для Windows: (Терминал можно открыть, нажав Win+R и введя 'cmd')
> ```bat
> echo {"accounts": [{"entitlement": {"canPlayMinecraft": true,"ownsMinecraft": true},"type": "MSA"}],"formatVersion": 3} > %appdata%/PrismLauncher/accounts.json
> ```
> Для Linux:
> ```sh
> echo '{"accounts": [{"entitlement": {"canPlayMinecraft": true,"ownsMinecraft": true},"type": "MSA"}],"formatVersion": 3}' > ~/.local/share/PrismLauncher/accounts.json
> ```
> Для Linux (если Prism установлен через Flatpak):
> ```sh
> echo '{"accounts": [{"entitlement": {"canPlayMinecraft": true,"ownsMinecraft": true},"type": "MSA"}],"formatVersion": 3}' > ~/.var/app/org.prismlauncher.PrismLauncher/data/PrismLauncher/accounts.json
> ```
> Для macOS:
> ```sh
> echo '{"accounts": [{"entitlement": {"canPlayMinecraft": true,"ownsMinecraft": true},"type": "MSA"}],"formatVersion": 3}' > ~/Library/Application\ Support/PrismLauncher/accounts.json
> ```

## Версия и моды
Сервер работает на ядре **Fabric** и версии Minecraft **26.2**. Далее будет предоставлен список модов для игры.

### Серверные моды
Установка этих модов на клиент **НЕ ТРЕБУЕТСЯ**, но они работают на сервере.

#### Fabric-моды
* **2032 World Height** - увеличивает максимальную высоту строительства до 2032 блоков
* **AppleSkin** - улучшение интерфейса здоровья и голода (серверная часть)
* **Auth** - авторизация по паролю
* **Chunky** - инструмент для генерации чанков
* **Immersive Paintings** - мод для добавления кастомных картин (серверная часть)
* **Invisible Frames** - возможность сделать рамку невидимой через Shift+ПКМ
* **Just Enough Items** - браузер рецептов (клиентская часть)
* **Ledger** - логирование всех событий на сервере
* **RW Sheld Mod** - [кастомный мод](https://github.com/SpdrSO/rwsheld-mod) для нашего сервера
* **Set World Spawn Point** - конкретная точка респавна
* **Skin Restorer** - подтягивает скины по нику с серверов Mojang и по команде `/skin` с [Ely.by](https://ely.by/)
* **Spark** - анализ нагрузки на сервер
* **Simple Voice Chat** - голосовой чат (серверная часть)
* **Clumps**, **Ferrite Core**, **Krypton**, **Lithium**, **ModernFix** - оптимизация производительности сервера
* **Collective**, **Fabric API**, **Fabric Language Kotlin**, **Fzzy Config** - зависимости для вышеперечисленных модов

#### Дата-паки
* **Minecart Improvements** - официальный датапак для улучшения вагонеток (у нас максимум их скорости поднят в 4 раза)

### Обязательные моды
Эти моды **ОБЯЗАТЕЛЬНЫ** к установке на клиент для стабильной игры на сервере.
* **Immersive Paintings** - мод для добавления кастомных картин (клиентская часть)
* **Simple Voice Chat** - голосовой чат (клиентская часть)
* **Fabric API**, **Fabric Language Kotlin**, **Fzzy Config** - зависимости для вышеперечисленных модов

### Рекомендуемые моды
Эти моды не обязательны, чтобы зайти на сервер, но улучшают игровой опыт. Вы можете пополнить этот список удобными вам клиентскими модами или исключить ненужные для вашей сборки.
* **AppleSkin** - улучшение интерфейса здоровья и голода (клиентская часть)
* **Chat Heads** - отображение аватарок игроков в чате
* **Continuity** - соединённые текстуры стекла и некоторых других строительных блоков (требуется активировать встроенный ресурспаки)
* **Iris** - поддержка шейдеров
* **Just Enough Items** - браузер рецептов (клиентская часть)
* **LambDynamicLights** - доработка освещения
* **Mod Menu** - меню настройки модов
* **Xaero's Minimap** - миникарта и маркеры места смерти
* **Xaero's World Map** - полноэкранная карта мира
* **Zoomify** - зум на клавишу C
* **Ferrite Core**, **Lithium**, **Sodium** - оптимизация производительности клиента
* **Fabric API**, **Fabric Language Kotlin**, **Placeholder API**, **YetAnotherConfigLib** - зависимости для вышеперечисленных модов

### Установка модов
Моды можно скопировать из архива `rwsheld-mods.zip` в [разделе релизов](https://github.com/SpdrSO/rwsheld-info/releases) в папку модов вашей сборки или вручную с сайтов [Modrinth](https://modrinth.com/discover/mods) и [CurseForge](https://www.curseforge.com/minecraft) (кастомный мод [вот тут](https://github.com/SpdrSO/rwsheld-mod/releases)). Там же доступны ресурспаки, шейдеры и т.д. В Prism Launcher всё это можно сделать сразу через интерфейс программы.

## Подключение к серверу
К серверу можно подключиться по одному из двух доменов:
* `rwsheld.joinserver.xyz` - прямое подключение с минимальным пингом
* `rwsheld.joinserver.ru` - подключение через прокси для обхода пранков от РКН

Если у вас не работает один из доменов, обязательно попробуйте другой - бывает даже такое, что с прокси не работает, а без него всё в порядке.

## Авторизация
> На сервере действует вайт-лист, для попадания в который требуется отправить сообщение в [дискорд-ветку](https://discord.com/channels/958653033342959666/1531970067305074789), содержащее ваш майнкрафт ник. 

Так как наш сервер не требует лицензии для входа, пользователю надо будет авторизовываться при каждом подключении. Пароль может состоять только из цифр. В целях безопасности, просьба не использовать ваши реальные пароли.
* Команда для регистрации: `/trigger register set <пароль>` (алиасы: `/login <пароль>`, `/log <пароль>`, `/l <пароль>`)
* Команда для последующего входа: `/trigger register set <пароль>` (алиасы: `/register <пароль>`, `/reg <пароль>`, `/r <пароль>`)
